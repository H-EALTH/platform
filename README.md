# platform

Workflow riusabili (`workflow_call`) che i prodotti H-EALTH chiamano da `ci.yml` e `release.yml`,
pinnati al tag completo `vX.Y.Z`.

La documentazione dell'infrastruttura, il registro degli ADR citati nei commenti dei workflow
e le procedure di rilascio sono in [H-EALTH/docs](https://github.com/H-EALTH/docs).
